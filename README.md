# SC2 Conveyor Profiler

모바일과 데스크톱 브라우저에서 사용하는 SC2 컨베이어 프로파일 확인용 시뮬레이터입니다.

- 실행 주소: https://alzza.github.io/sc2-conveyor-profiler/
- iPhone/iPad: Safari
- Android: Chrome
- 데스크톱: Chrome, Edge, Safari

## 주의

이 화면은 CSM 프로그램 계산과 수집한 Trend CSV를 이해하기 위한 보조 도구입니다. 표시되는 추천값은 PLC에 자동 적용되지 않으며, 실제 설비 변경값을 확정하지 않습니다. 현장 변경은 안전검토, 저속 시험, 승인 절차를 거쳐야 합니다.

선택한 CSV는 현재 브라우저 메모리에서만 분석합니다. 이 페이지는 CSV를 GitHub 또는 외부 서버로 전송하지 않습니다.

휴대폰 파일 앱이나 메신저의 HTML 미리보기는 JavaScript를 실행하지 않을 수 있습니다. 위 GitHub Pages 주소를 Safari 또는 Chrome에서 직접 여십시오.
